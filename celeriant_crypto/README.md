# celeriant_crypto

Internal crate. Cryptographic identity, authentication, and PKI for [Celeriant](https://celeriant.io).

Covers node identity derivation, nonce-based client authentication, API key management, and X.509 certificate generation for TLS/mTLS.

If you're building a client application, use [`celeriant_client_tokio`](https://crates.io/crates/celeriant_client_tokio) instead.
