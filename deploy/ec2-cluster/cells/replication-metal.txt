# Rung 4 — replication-delay sweep, replicated pair, single AZ, i4i.metal.
#
# fsync pinned at 1,000 µs — the value rung 2 established as inside the plateau on BOTH
# storage classes — so the fsync knob cannot confound the replication axis.
#
# Unlike fsync, this delay amortises a NETWORK round-trip to the follower, not a device
# flush. Same-AZ RTT is ~50-100 µs, so the floor is two orders of magnitude below the fsync
# floor and the plateau may start much lower. The interesting question is whether the ~6-8 ms
# upper edge seen on both storage classes reappears here — if it does, it is not a storage
# property at all, which is the open question F-12 leaves.
#
# Requires dataNodeCount=2 and STANDALONE unset; deploy.sh hard-rejects the mismatched pairing.

repl_250      REPLICATION_DELAY_US=250   FSYNC_DELAY_US=1000
repl_1000     REPLICATION_DELAY_US=1000  FSYNC_DELAY_US=1000
repl_4000     REPLICATION_DELAY_US=4000  FSYNC_DELAY_US=1000
repl_8000     REPLICATION_DELAY_US=8000  FSYNC_DELAY_US=1000
repl_17000    REPLICATION_DELAY_US=17000 FSYNC_DELAY_US=1000
repl_34000    REPLICATION_DELAY_US=34000 FSYNC_DELAY_US=1000
